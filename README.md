# Как из 3,5 млн сделать 12 за год

В `access.log` nginx за год легко набегает **3,5 млн** строк (и диск забивается одним огромным файлом).

## Решение

Настроить **logrotate** с месячной ротацией: `monthly` + `rotate 12`.

За год вместо одного гигантского лога получится **12** сжатых архивов.

Конфиг: [`logrotate.d/nginx`](logrotate.d/nginx) → положить в `/etc/logrotate.d/nginx`.

```bash
# проверка без изменений
sudo logrotate -d /etc/logrotate.d/nginx

# принудительный прогон
sudo logrotate -f /etc/logrotate.d/nginx
```

После ротации nginx переоткрывает логи по сигналу `USR1` (без рестарта и без обрыва соединений).

В репозитории также лежит дефолтный [`nginx.conf`](nginx.conf).
